11. Quarkus x Aviation
Le but de cet exercice est de créer une mini API REST ainsi qu’un mini site l’accompagnant en se basant sur le Cas pratique: Aviation.sql.

À faire

Créer un utilisateur airplane depuis l’utilisateur system

Donner tous les droits à cet utilisateur sur son schéma

Créer la base de données aviation à partir du présent sur la page du cas pratique

Créer une mini API REST exposant les ressources
Avions de ligne (avec leur moteur associé)

Compagnies (avec leurs flottes associées)

Créer une page permettant de sélectionner une compagnie aériennes et d’afficher:
le nombre de modèles d’avion différents exploités,

les modèles d’avions différents exploités avec leurs caractèristiques et la table de la flotte.

Créer une page permettant de sélectionner un type d’avion et d’afficher:
ses caractèristiques,

les compagnies qui l’exploitent (avec la taille de la flotte pour chacune).

Indication

Il est convenu d’utiliser une base de données oracle pour cet exercice, un projet Quarkus avec panache ORM et pour les pages web la librarie Qute dont vous pouvez avoir un aperçu ci-dessous.

11.1. Quarkus Qute
Qute est un moteur de template développé spécifiquement pour Quarkus. En mode développement, tous les fichiers situés dans src/main/resources/templates sont surveillés pour les changements, et les modifications deviennent visibles immédiatement.

11.1.1. Service un template Qute via HTTP
La dépendance maven
<dependency>
    <groupId>io.quarkiverse.qute.web</groupId>
    <artifactId>quarkus-qute-web</artifactId>
</dependency>
Si vous voulez rendre un template QUTE via HTTP:

Tout template situé dans src/main/resources/templates/pub/ sera automatiquement rendu sans besoin de code Java.
src/main/resources/templates/pub/helloworld.html sera disponible à l’url /foo et /foo.html par défaut.

Pour un contrôle plus fin, nous combinerons nos template avec des ressource REST.

Important

Tout fichiers situés dans src/main/resources/templates sera enregistré comme un template et pourra être injecté dans une ressource REST.

src/main/resources/templates/pub/hello.html
<h1>Hello {http:param('name', 'Quarkus')}!</h1>
En accédant à la page http://localhost:8080/hello?name=Sam vous devriez obtenir une page HTML.

11.1.2. Quarkus QUTE & REST
Nous pouvons contrôler plus finement nos templates, en les associant à une ressource REST.

La dépendance maven
<dependency>
    <groupId>io.quarkus</groupId>
    <artifactId>quarkus-rest-qute</artifactId>
</dependency>
hello.txt
Hello {name}!
HelloResource.java
package org.acme.quarkus.sample;

import jakarta.inject.Inject;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.QueryParam;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.core.MediaType;

import io.quarkus.qute.TemplateInstance;
import io.quarkus.qute.Template;

@Path("hello")
public class HelloResource {

    @Inject
    Template hello;

    @GET
    @Produces(MediaType.TEXT_PLAIN)
    public TemplateInstance get(@QueryParam("name") String name) {
        return hello.data("name", name);
    }
}
