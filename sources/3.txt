3. Rappels sur Oracle
3.1. Installation d’une image podman
Indication

Pour en savoir un peu plus sur Podman et avoir quelques commandes de survie, rendez-vous sur cette page : Podman

Nous allons pull l’image oracle-free puis créer un container pour celle-ci et enfin démarrer celui-ci.

podman pull gvenzl/oracle-free
podman run --name oracle -dt -p 1521:1521 -e ORACLE_PASSWORD=admin gvenzl/oracle-free
podman start oracle
Indication

Si l’on souhtaite mettre à jour le mot de passe de l’utilisateur system

podman exec oracle resetPassword admin
Il nous est possible de nous connecter avec l’utilisateur system en ligne de commande sqlplus system/admin@//localhost/FREEPDB1 ou d’utiliser l’extension pour vscode .

Nous allons paramètrer une connexion vers notre utilisateur system.
